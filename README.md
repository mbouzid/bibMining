# bibMining

Repository of the scripts employed in 'Mining and Floods: A Systematic Review of Empirical Studies on Community Resilience Strategies and Interventions'


## Content

* `src/keyword_clustering.ipynb`: This notebook generates a keywords clustering of the studies. The output file is in EPS format.

* `src/histo_num_papers.ipynb`: This notebook generates a histogram of the number of papers published per year in the corpus. The output file is in EPS format.

* `src/map_articles.ipynb`: This notebook generates a map of the studies. The output file is in EPS format.


* `src/citation_network.ipynb`: This code generate a co-citation graph of the corpus. The output are in PDF and PGF formats.
